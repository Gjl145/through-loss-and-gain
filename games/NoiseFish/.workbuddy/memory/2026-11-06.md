## 第 2 步：多段鱼身 + 分段消散

- 鱼从单球体拆成 **头/身/尾三段**，各段独立 GameObject + FishSegment 组件
- 消散顺序 = 头 → 身 → 尾（segments 数组头部 = 最先消散）
- 关键技术点（都踩过坑）：
  - FishSegment 必须**缓存初始尺寸**（Awake 里 baseScale = target.localScale），
    Apply 乘在初始尺寸上而不是当前尺寸 → 否则 SetPresence 每帧调用会**累积缩小**
  - 整鱼尺寸改用 `FishActor.SetOverallScale()`，**不再改父物体 transform.localScale**
    （否则父级 scale 与段缩放叠加 → 鱼会缩水一半）
  - alpha 归零时**关闭 Renderer**，不能靠 scale 下限（会留 0.0034 残影）
  - 段位置必须**计算过**保证首尾交叠，否则散成三个球
- 验证手段：用 Python 模拟缩放数学（显形 60 帧 + 重复调用 100 次 + 消散归零 + 三段连通）
