# 游戏作品集 · Game Portfolio

个人游戏开发项目的**总容器仓库**。每个游戏作为独立子目录，按项目名分类，便于统一管理与检索。

> 为什么不一项目一仓库？
> 早期项目（zhizhu / pukepai 等）各自独立建仓。
> 本仓库用于收纳**尚未单独建仓**的新项目，避免仓库列表膨胀；
> 若某个项目后续独立成仓，此处保留目录并注明迁移去向。

---

## 约定

- **每个项目独立成子目录**，目录内自包含（含自己的 `.gitignore`）
- Unity 生成物（`Library/` `Temp/` `obj/` `Logs/` `UserSettings/`）一律不入库
- 提交粒度：**一次变更一个提交**，分支用 `feature/<序号>-<简述>` / `fix/<序号>-<简述>`
- 沙箱无 Unity 时，用项目内的 `.workbuddy/tools/cscheck.py` 做编译前静态自检
